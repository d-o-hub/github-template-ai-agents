## Innovation Opportunity (TRIZ)

**Principle 23 — Feedback**: The 37.8% change failure rate is driven by bot self-fix loops where multiple iterations of `fix(...)` commits are needed to pass CI. Local hooks already validate quality (pre-commit runs `quality_gate.sh`) and commit messages (`commit-msg` hook validates commitlint rules). The remaining CI failures come from bot-driven workflows, not human bypasses. Consider adding a **local CI simulation** (`act`-based) that bots run before pushing to reduce fix iterations.

**Principle 35 — Parameter Change**: `.agents/metrics.jsonl` is a template entry after intentional reset. The Post-Task Protocol remains opt-in. Converting it to an **automated hook** (e.g., a post-agent-session hook that appends after each agent task completion) would close the observability gap without adding agent overhead. Alternatively, switch to a **time-series database** approach where each agent owns its own metrics file, avoiding the single-file merge-conflict problem that prompted the reset.
