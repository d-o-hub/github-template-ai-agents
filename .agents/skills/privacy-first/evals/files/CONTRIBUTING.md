# Contributing

Thanks for taking the time to contribute.

## How to contribute

1. Fork the repository and create a branch.
2. Make your change, keeping commits focused.
3. Run the checks before opening a pull request.
4. Open a PR describing what changed and why.

## Code of conduct

Be respectful. Assume good faith, and prefer concrete suggestions over general
criticism.

## Contact

For questions about this project, open a discussion in the repository. Please do
not add personal email addresses to this file — use a team alias or an issue
tracker form instead.
