Optimized bash scripts by removing process-forking bottlenecks:
1. check-skill-references.sh: Added regex fast-path checks.
2. check-lessons-consistency.sh: Replaced grep checks in loops
with native declare -A associative array lookups.
3. gh-labels-creator.sh and lib/lang-checks.sh: Replaced
while read subshell pipelines with mapfile.

Running external commands (grep, subshells) inside loops is
a known Bash performance anti-pattern. These operations create
thousands of unnecessary process forks.

Measured execution time reductions:
- check-skill-references.sh: ~11s down to ~1s
- check-lessons-consistency.sh: ~1.1s down to ~0.3s
