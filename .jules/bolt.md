## 2026-10-04 - Native Bash Regex Instead of Subshells
**Learning:** External command pipelines like `printf | grep | head | grep` inside loops are extremely slow because each pipeline spawns multiple subprocesses. `mapfile -d` is NOT a safe alternative to `while IFS= read -r -d ''` loops because it was introduced in Bash 4.4, breaking compatibility with macOS which defaults to Bash 3.2.
**Action:** Always prefer native Bash capabilities like regex matching (`[[ $var =~ regex ]]` and `BASH_REMATCH`) and parameter expansion to extract patterns, avoiding `mapfile -d` optimizations that sacrifice OS compatibility.
